艦隊札管理帖とは

「艦隊これくしょん -艦これ-」の期間限定イベントに向けて、どの艦娘にどの出撃札を付けるかを出撃前にブラウザ上で計画したり、札を既に付与した艦娘を管理することで攻略に役立てるためのサイトです。手持ちの艦娘・海域ごとの特攻値・札の割り当てを 横に並べて見比べながら、編成を組み立てられます。

開催中のイベントがすぐ開きます デフォルトでは最新のイベントの情報を表示します。もし過去のイベント情報を確認したい場合は、画面左上の イベント選択 プルダウンから選択できます。

画面は3つの表でできています

  • 制御札管理（左の表） 艦娘ごとの札の割り当てを記録する表です。ここで札の配分を検討し、記録します。
  • 艦船情報（中央の表） 手持ちの艦娘の一覧です。ここで着任状況（所持しているかどうか）を反映させます。
  • 海域特攻情報（右の表） 海域ごとの特攻値の一覧です。どの艦をどこに出すと効果的かを確認します。

作業の流れ

  1. 着任状況を反映する

    手持ちの艦娘を画面に反映させます。クリックで1隻ずつ、CSV や艦隊分析コードでまとめて、の いずれでも行えます。→ ①着任状況を反映する タブ

  2. 特攻値を確認する

    海域ごとの特攻艦と倍率を見て、出撃先の候補を絞ります。→ ②特攻値を確認する タブ

  3. 札を割り当てる

    艦娘ごとに出撃先の海域と札を決めていきます。→ ③札を割り当てる タブ

PC での利用を想定しています 横に3つの表を並べる画面構成のため、スマートフォンなど幅の狭い画面では正しく表示されない場合があります。

①着任状況を反映する― 艦船情報表

画面中央の 艦船情報 が、手持ちの艦娘を管理する表です。 ここに着任状況（所持しているかどうか）を反映させるところから始めます。

艦船情報表の見かた

  • 詳細表示 / 艦名のみ 表示密度を切り替えます。多くの艦を一度に見渡したいときは「艦名のみ」が便利です。
  • 未所持艦を表示する まだ着任していない艦娘も一覧に含めます。着任状況を入力するときはこちらに切り替えます。
  • 艦種タブ 画面上部のタブ（駆逐 / 軽巡 / 戦艦 …）で艦種を絞り込めます。複数選択もできます。

方法1: クリックで反映する（基本）

いちばん手軽な方法です。特別な準備は要りません。

  1. 未所持艦を表示する

    艦船情報の 未所持艦を表示する を押して、まだ着任していない艦娘も一覧に出します。

  2. 所持数を増やす

    各行の ＋ を押すと所持数が1つ増え、着任済みとして扱われます。 同じ艦を複数所持している場合は、その数だけ押してください。

  3. 複数所持の艦は行が増える

    2隻目以降は (2隻目) (3隻目) と表示され、行が分かれます。 1隻ずつ別々の海域へ割り当てられるので、増設した分だけ計画を立てられます。

  4. 間違えたら戻す

    − を押すと所持数が1つ減ります。0 にすると未所持の状態に戻ります。

先に着任させてください 未着任の艦娘には札を割り当てられません。③で札を付けようとして反応しない場合は、 まずこの表で着任状態にしてください。

方法2: CSV から取り込む（艦船のみ）

手持ちの艦名リストがある場合は、こちらでまとめて反映できます。 画面最上部の csvから取り込み(艦船のみ) ボタンから、 艦名のみを改行区切りで並べたファイルを読み込みます。

  • 文字コードは UTF-8 / Shift_JIS を自動判定します
  • 反映されるのは着任状況だけで、レベルなどの情報は含まれません
  • 同名で複数の候補がある艦は、どれを指すか選ぶダイアログが表示されます

方法3: 艦隊分析コード（JSON）から取り込む

制空権シミュレータなど、艦隊分析コードに対応したツールを使っている場合は、そのコードを貼り付けるだけで レベルや改造状態まで含めて反映できます。

  1. コードを貼り付ける

    画面最上部の 艦隊分析コード（JSON） の入力欄に貼り付けます。

  2. 取り込む

    コードから取り込み を押します。

  3. 取り込み先を選ぶ

    現在のタブに上書き か 新規データセットに出力 を選びます。

「現在のタブに上書き」に注意 上書きを選ぶと、現在のデータセットの所持数データが取り込み内容で置き換わります。 今の内容を残しておきたい場合は「新規データセットに出力」を選んでください。
より高度な方法: 艦隊分析コードを自分で取得する

艦隊分析コードをまだ持っていない場合は、艦これのブラウザ画面から通信内容を取り出し、 艦隊分析に対応したツール（制空権シミュレータ 等）に読み込ませて出力します。 ブラウザの開発者ツールを使うため、慣れていない方は上の 方法1・方法2 をおすすめします。

  1. 開発者ツールを開く

    艦これのゲーム画面を開いた状態で右クリックし、開発者ツールで調査する（Firefox では 検証）を選びます。

  2. ネットワークタブで記録を開始する

    ネットワーク タブを開き、記録ボタン（赤丸）が有効なことと、フィルタが すべて になっていることを確認します。その状態で GAME START を押してログインします。

  3. 所持艦娘のデータをコピーする

    一覧から port を探して右クリックし、 コピー → 応答のコピー を選びます。これが母港（所持艦娘）のデータです。

  4. 所持装備のデータをコピーする

    装備の情報も必要な場合は、同じ手順で require_info の応答をコピーします。

  5. 艦隊分析コードを出力する

    コピーした内容を艦隊分析コードに対応したツールに読み込ませ、艦隊分析コードを出力します。 あとは上の 方法3 の手順で貼り付けます。

②特攻値を確認する― 海域特攻情報表

画面右側の 海域特攻情報 が、海域ごとの特攻値をまとめた表です。 左の2つの表と行が揃っているので、着任している艦の特攻値だけを横並びで確認できます。

表の見かた

  • 行 = 艦娘 艦船情報の表と同じ行が並びます。絞り込みも連動します。
  • 列 = 海域 イベントの各海域が列になります。上段に札、下段に海域が表示されます。
  • セル = 特攻倍率 その艦をその海域に出したときの倍率です。値の大きさに応じて色が付きます。

イベントを選択していないときは表示されません。まず左上のプルダウンでイベントを選んでください。

特攻値の高い順に並べ替える

海域のヘッダをクリックすると、その海域の特攻値で全体が並べ替わります（もう一度押すと昇順・降順が入れ替わります）。 「この海域に出すならどの艦が有効か」を一発で把握できるので、割り当てを決める前にまずこれを使うのが近道です。

並べ替えと折りたたみ

  • 札で並べ替え / 海域で並べ替え … 列のまとめ方を切り替えます。札単位で見ると「この札をどこで使用するか」が把握しやすくなります
  • 全展開 / 全格納 … 海域グループをまとめて開閉します。見たい海域だけ開いておくと横幅を節約できます

編成サンプルを見る

海域のヘッダをダブルクリックすると、その海域の編成サンプルが表示されます（用意されている海域のみ）。

装備の特攻を調べる

艦娘だけでなく装備にも特攻があります。画面上部の 装備特攻 ボタンから確認できます。

  • 装備種別 / 搭載先 / 対象海域 で絞り込み
  • 装備をチェックすると掛け合わせの式が出ます（最大5つまで）
  • クリアボタンで選択をまとめて解除できます
倍率の出典について 特攻倍率は外部の情報を出典としています。表の右上に出典名と参照時点が表示され、リンクから原典を確認できます。 イベント開催直後は情報が更新されることがあるため、重要な判断の前は出典もあわせてご確認ください。

③札を割り当てる― 制御札管理表

画面左側の 制御札管理 が、このツールの中心となる表です。 艦娘ごとに「どの海域に出すか」「どの札が付くか」「使わずに温存するか」を記録していきます。

各列の意味

  • 割当先 出撃させる予定の海域（例: E-4-3）です。まだ札が付いていない「予定」の状態を表します。
  • 割当札 割当先の海域で付く札です。海域を選ぶと候補から選択できます。
  • 割当済 実際にゲーム内で札が付いた艦を表します。予定と実績を区別するための項目です。
  • 温存 このイベントでは出撃させない、と決めた艦に付けます。割当済の艦は温存にできません。
  • コメント 自由記入のメモ欄です。コメント欄表示 で表示を切り替えます。

割り当ての手順

  1. 表から直接割り当てる（最短）

    制御札管理の 割当先 のセルをクリックすると、 海域 → 小海域 → 札 の順にメニューがたどれます。まとめて割り当てるときはこれが一番速い方法です。

  2. 艦娘の詳細から割り当てる

    艦船情報の艦名をクリックすると詳細が開き、そこでも同じ操作ができます。 改装段階や艦型を確認しながら決めたいときはこちらが便利です。

  3. 実際に出撃したら「割当済」に切り替える

    「割当前」の表示をクリックすると「割当済」に変わります。予定と実績を分けておくことで、 計画を見直している最中でも、実際に札が付いてしまった艦を取り違えずに済みます。

同じ札が複数の海域で使われることがあります そのため本ツールでは札だけでなく「割当先の海域」も一緒に保持しています。 エクスポートしたコードを読み込み直したときも、海域の情報が保たれます。

割り当て状況を確認する

割当済 や 割当札 の列で絞り込めば、 「この札を付けた艦だけ」を一覧できます。艦種タブと組み合わせると、 札ごとの艦種の偏りや不足を把握しやすくなります。

便利な使い方

キーボードで札の割り当てを繰り返す

同じ札を大量に割り当てるときに効きます。いずれも、割り当てたい行にマウスを乗せた状態で押します。

  • Ctrl + D 一つ上の行の札情報を、カーソルが乗っている行へ複製します。
  • F4 直前に行った割り当てを、カーソルが乗っている行へ繰り返します。

割当済の艦を上書きしようとした場合は確認ダイアログが出るので、誤操作の心配はありません。

絞り込みを組み合わせる

各表のヘッダ右下にある虫眼鏡アイコンから、その列の値で絞り込めます。絞り込み中はヘッダの色が変わり、 アイコンがフィルタの形になります。3つの表の絞り込みは連動するため、 「特攻を持つ艦のうち、まだ札を割り当てていない駆逐艦」といった見方ができます。

  • 艦名で検索（部分一致・ひらがな、カタカナ、ローマ字読みに対応）
  • 艦型・艦番で検索
  • 速力で絞り込み
  • 対地装備で絞り込み
  • 艦種タブ（複数選択可・まとめて選択／解除）

改造段階を切り替える

特攻倍率は改造段階によって変わります。艦名の右にある ▼ を押すと改装段階の一覧が出るので、そこから切り替えると特攻表の値もその段階のものに変わります。 改装元と倍率が異なる場合は、その旨の注意が表示されます。

プランを分けて持つ（データセット）

イベントごと、あるいは「甲でいく案」「乙に落とす案」のように、複数のプランをデータセットとして 分けて保存し、画面上のタブで素早く切り替えられます。名前の変更・複製・削除も行えます。

表示テーマを変える

ライト / ダーク / ダークブルー の3種類から選べます。長時間の作業では暗いテーマが目に優しく、 この使い方ページの配色も選択に合わせて変わります。

メモを残す

コメント欄表示 を押すと、艦娘ごとに自由記入のメモを書けます。 「掘り要員」「高速化が必要」など、後から自分が迷わないための覚え書きに使えます。

その他

データは自動でブラウザに保存されます

入力した内容（所持艦娘・札の割り当てなど）は、すべてお使いのブラウザ内（IndexedDB）に保存されます。 外部サーバーに送信されることはありません。サイトの表示に必要なマスタデータ（イベント情報・艦船一覧など）の 取得のため Firebase との通信、および利用状況の把握のため Google Analytics によるアクセス解析を行っています。

ブラウザのデータを消すと失われます 「閲覧データの削除」やプライベートウィンドウの終了、別のブラウザ・別の端末への移行では、 保存内容は引き継がれません。大事な計画は下記のエクスポートでバックアップしてください。

バックアップと持ち出し

コードを生成 を押すと、現在のデータセットの内容が艦隊分析コード（JSON）として入力欄に出力されます。 コピーボタンでクリップボードに控えておけば、コードから取り込み でいつでも復元できます。別の端末へ移すときもこの方法が使えます。

出力されるコードは一般的な艦隊分析コードの形式に、本ツール独自の割り当て情報を追加したものです。 他のツールは知らない項目を無視するため、そのまま他ツールに読み込ませることもできます。
